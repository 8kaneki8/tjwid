# بيانات المصحف

لا تضع نصًا قرآنيًا مولدًا أو منسوخًا من مصدر غير موثق هنا.

## المصدر المعتمد مبدئيًا
Tanzil Quran Text – Uthmani، رواية حفص عن عاصم:
- التنزيل الرسمي: https://tanzil.net/docs/download
- الترخيص: https://tanzil.net/docs/text_license
- النص يجب أن يبقى حرفيًا دون تعديل. أدرج إشعار حقوق النشر ونسبة المصدر ورابط tanzil.net مع أي نسخة.

## بنية الملف المطلوبة
بعد الحصول على ملف المصدر والتحقق من نسخته، حوّله إلى JSON دون تغيير محتوى الآيات:
`quran.json`:
- `source`: اسم المصدر وإصداره.
- `riwayah`: `Hafs an Asim`.
- `surahs`: 114 عنصرًا مرتبة، لكل عنصر `id`, `name`, `verses`, و`ayahs`.
- كل آية لها `number` و`text` من المصدر كما هو.

لا تُنشئ بيانات أرقام الصفحات أو الأجزاء تخمينًا. اربطها بمرجع مستقل موثق عند توفره.
