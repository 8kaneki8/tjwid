# بيانات المصحف

## ملف النص المعتمد
يوضع الملف الأصلي هنا بالاسم الدقيق: `quran-uthmani.txt`.

المصدر: **Tanzil Quran Text (Uthmani, Version 1.1)**، رواية حفص عن عاصم.
- الموقع الرسمي: https://tanzil.net
- صفحة التنزيل: https://tanzil.net/docs/download
- الترخيص: Creative Commons Attribution 3.0 — https://tanzil.net/docs/text_license

**تنبيه مهم:** يجب إبقاء الملف الأصلي كما نُزّل، بما في ذلك جميع أسطر التعريف وحقوق النشر في بدايته. لا تُعدّل رسم الآيات أو التشكيل أو علامات الوقف، ولا تحذف إشعار الحقوق.

## طريقة القراءة
يقرأ الموقع ملف النص مباشرة بصيغة Tanzil المفصولة بعلامة `|`:
`رقم السورة|رقم الآية|نص الآية`

يتجاهل قارئ الموقع أسطر التعليقات التي تبدأ بـ `#` عند بناء الآيات، لكنه لا يغيّر الملف نفسه. أسماء السور وأعداد آياتها معرفة في التطبيق للتحقق من الترتيب.

## التحقق
شغّل:

```bash
npm run validate:quran
```

يتحقق الفاحص من بيانات المصدر والترخيص، ووجود 114 سورة و6236 آية، وتسلسل أرقام السور والآيات، وعدم وجود نصوص فارغة. هذا فحص بنيوي وليس مراجعة بشرية مستقلة لكل حرف.

لا تُضف أرقام صفحات أو أجزاء أو أحزاب ما لم تتوفر بيانات موثقة مستقلة.
