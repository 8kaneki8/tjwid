# محرك التسميع القرآني المفتوح

خدمة API مستقلة لموقع تجويد، تستخدم نموذج **Abdou/quran-asr-small** المرخّص MIT عبر sherpa-onnx. حجم نموذج INT8 نحو 36 MB، وهو مخصص للتعرف على التلاوة القرآنية ويعمل على CPU. أرقام الدقة المذكورة في بطاقة النموذج نتائج تقييم منشورة من صاحب النموذج وليست ضمانًا لنتيجة كل مستخدم.

## النشر المجاني

1. أنشئ Space جديدًا في Hugging Face واختر Docker.
2. انسخ محتويات هذا المجلد إلى مستودع الـ Space (الملفات: `README.md`, `Dockerfile`, `requirements.txt`, `app.py`).
3. اختر CPU Basic المجاني إن كان متاحًا لحسابك. قد ينام الـ Space عند عدم الاستخدام ويحتاج وقتًا ليستيقظ.
4. من إعدادات Space أضف المتغير:
   - `ALLOWED_ORIGINS=https://8kaneki8.github.io`
5. انتظر اكتمال البناء وتحميل النموذج، ثم افتح:
   - `https://YOUR-SPACE.hf.space/v1/health`

يجب أن ترجع الاستجابة `"ok": true` و`"model_loaded": true`.

## ربط الموقع

في صفحة القرآن، ضع رابط Space في حقل «رابط محرك التسميع» أسفل المصحف ثم احفظه. لا تضع أي مفتاح سري في JavaScript أو مستودع GitHub.

## API

- `GET /v1/health` — حالة تحميل النموذج.
- `POST /v1/transcribe` — حقل multipart اسمه `audio` ويقبل مقاطع MediaRecorder القصيرة.

الحد الافتراضي للمقطع 12 ثانية و4 MB، مع تحديد معدل الطلبات. الصوت يُرسل إلى Space الذي تنشره؛ لا ترفع تسجيلات أشخاص آخرين دون إذنهم.

## حدود الدقة

النموذج يتعرف على الحروف/الكلمات القرآنية ويعيد نصًا، ثم يقارنه الموقع بنص الآية. هذا لا يثبت صحة التجويد أو المدود أو المخارج، ولا ينبغي استخدامه كبديل عن معلّم متقن. قد يخطئ التعرف خصوصًا مع الضوضاء أو اختلاف سرعة القراءة.
