# محرك التسميع القرآني — تجويد

هذا المجلد هو الجزء الصوتي من مشروع **تجويد**. واجهة المصحف ومشغل التلاوة والتسميع موجودة في جذر المستودع، بينما تعمل خدمة التعرف الصوتي من هذا المجلد. الاثنان جزء من مستودع واحد، ولا يحتاج المشروع إلى موقع ثانٍ.

## كيف يعمل التكامل؟

1. يختار القارئ السورة والآية من المصحف في الموقع.
2. يلتقط المتصفح الصوت بموافقة المستخدم باستخدام MediaRecorder.
3. يرسل الموقع مقاطع صوتية قصيرة إلى هذه الخدمة عبر `POST /v1/transcribe`.
4. تستخدم الخدمة نموذج **Abdou/quran-asr-small** عبر `sherpa-onnx` لإرجاع النص المتعرف عليه.
5. يقارن الموقع الكلمات بالنص القرآني المعروض ويبيّن الكلمات المطابقة أو التي تحتاج إلى مراجعة.

النموذج مفتوح المصدر بترخيص MIT. نتائج بطاقة النموذج المنشورة مرجعية وليست ضمانًا لدقة كل تسجيل.

## تشغيل المحرك محليًا

يتطلب التشغيل Docker، واتصالًا بالإنترنت عند أول تشغيل لتنزيل ملفات النموذج من Hugging Face.

من جذر المستودع:

```bash
docker build -t tjwid-quran-asr ./asr-api
docker run --rm -p 7860:7860 \
  -e ALLOWED_ORIGINS="https://8kaneki8.github.io,http://localhost:5500,http://127.0.0.1:5500" \
  tjwid-quran-asr
```

بعد اكتمال التحميل، اختبر:

```
http://localhost:7860/v1/health
```

يجب أن يعيد الفحص `"model_loaded": true`. اترك نافذة تشغيل Docker مفتوحة أثناء التجربة.

## ربط الموقع بالمحرك

- افتح الموقع، وانتقل إلى قسم **التسميع والمتابعة** أسفل المصحف.
- أدخل `http://localhost:7860` عند تشغيل الموقع والمحرك على الجهاز نفسه، ثم اضغط **حفظ وتجربة الرابط**.
- عند تشغيل الموقع على GitHub Pages، يجب أن تكون خدمة المحرك متاحة عبر عنوان HTTPS عام وأن تسمح قيمة `ALLOWED_ORIGINS` بعنوان الموقع.
- لا تضع مفاتيح وصول أو أسرارًا في ملفات JavaScript أو في المستودع.

## نقاط API

- `GET /v1/health`: حالة تحميل النموذج.
- `POST /v1/transcribe`: يستقبل ملفًا صوتيًا في حقل multipart اسمه `audio`.

الحد الافتراضي للمقطع 12 ثانية و4 MB، مع تحديد معدل الطلبات. الصوت الذي ترسله للمعالجة يصل إلى الخادم الذي تشغّله؛ لا ترسل تسجيلات أشخاص آخرين دون إذنهم.

## إعدادات اختيارية

- `ASR_MODEL_ID`: معرّف النموذج على Hugging Face.
- `ASR_MODEL_DIR`: مكان تخزين ملفات النموذج.
- `ASR_NUM_THREADS`: عدد خيوط المعالجة (الافتراضي 1).
- `ALLOWED_ORIGINS`: قائمة عناوين المواقع المسموح لها بالاتصال، مفصولة بفواصل.
- `MAX_AUDIO_BYTES` و`MAX_AUDIO_SECONDS`: حدود حجم ومدة المقطع.
- `RATE_LIMIT_PER_MINUTE`: حد الطلبات لكل عنوان IP.

## حدود مهمة

التعرف الصوتي يحاول تحويل التلاوة إلى كلمات؛ ومقارنة الكلمات ليست تقييمًا للتجويد أو المدود أو المخارج، ولا تثبت صحة القراءة. قد يخطئ النموذج بسبب الضوضاء أو اختلاف النطق أو سرعة القراءة. استخدم النتيجة للمراجعة المبدئية، وارجع إلى معلّم متقن عند تعلم التلاوة.
