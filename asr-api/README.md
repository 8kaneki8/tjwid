# محرك التسميع القرآني المفتوح

خدمة API مستقلة لموقع تجويد، تستخدم نموذج **Abdou/quran-asr-small** المرخّص MIT عبر sherpa-onnx. حجم نموذج INT8 نحو 36 MB، وهو مخصص للتعرف على التلاوة القرآنية ويعمل على CPU. نتائج التقييم المنشورة على بطاقة النموذج مرجعية وليست ضمانًا لنتيجة كل مستخدم.

## النشر المجاني المقترح: Render

1. افتح Render وسجّل الدخول، ثم اختر **New → Web Service**.
2. اربط مستودع `8kaneki8/tjwid` واختر الفرع `feat/quran-asr-engine`.
3. اختر Language: **Docker**.
4. اكتب **Root Directory**: `asr-api`.
5. اختر Compute: **Free**.
6. أضف متغير البيئة:
   - `ALLOWED_ORIGINS=https://8kaneki8.github.io`
7. أنشئ الخدمة وانتظر اكتمال البناء وتنزيل النموذج.
8. سيكون رابط الخدمة شبيهًا بـ `https://اسم-الخدمة.onrender.com`. اختبر:
   - `https://اسم-الخدمة.onrender.com/v1/health`
   - يجب أن تكون قيمة `model_loaded` هي `true`.

**قيود الخطة المجانية:** موارد Render المجانية محدودة إلى 512 MB RAM و0.1 CPU تقريبًا، وتنام الخدمة بعد 15 دقيقة من عدم الاستخدام، وقد يستغرق تشغيلها مجددًا قرابة دقيقة. كما أن مساحة الملفات مؤقتة؛ لذلك قد يُعاد تنزيل النموذج بعد إعادة التشغيل. الأداء الفعلي للتعرف يحتاج اختبارًا على هذه الموارد وقد يكون بطيئًا. راجع حدود Render الرسمية قبل الاعتماد عليها.

## بديل: Hugging Face Spaces

يمكن نشر مجلد الخدمة كـ Docker Space، لكن تشغيل Docker Space على CPU Basic بلا تكلفة بالساعة لا يعني أنه متاح للحسابات المجانية؛ إنشاء Docker Space يحتاج اشتراكًا مؤهلًا حاليًا. لا تعتمد هذا الخيار قبل مراجعة خطة حسابك.

## ربط الموقع

بعد نشر الخدمة، افتح صفحة القرآن، وضع رابط الخدمة في حقل «رابط محرك التسميع» أسفل المصحف ثم اضغط «حفظ وتجربة الرابط». لا تضع أي مفتاح سري في JavaScript أو مستودع GitHub.

## API

- `GET /v1/health` — حالة تحميل النموذج.
- `POST /v1/transcribe` — حقل multipart اسمه `audio` ويقبل مقاطع MediaRecorder القصيرة.

الحد الافتراضي للمقطع 12 ثانية و4 MB، مع تحديد معدل الطلبات. الصوت يُرسل إلى خدمة الاستضافة التي تنشرها؛ لا ترفع تسجيلات أشخاص آخرين دون إذنهم.

## حدود الدقة

النموذج يتعرف على الحروف/الكلمات القرآنية ويعيد نصًا، ثم يقارنه الموقع بنص الآية. هذا لا يثبت صحة التجويد أو المدود أو المخارج، ولا ينبغي استخدامه كبديل عن معلّم متقن. قد يخطئ التعرف خصوصًا مع الضوضاء أو اختلاف سرعة القراءة.
