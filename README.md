# تجويد | Tajweed

منصة قرآنية عربية للقراءة صفحة بصفحة، والاستماع للتلاوات، والتدرّب على الحفظ. الواجهة مبنية بـ HTML وCSS وJavaScript وتُنشر على GitHub Pages.

## المزايا الحالية
- مصحف نصي بترقيم صفحات مصحف المدينة (604 صفحة)، وليس صور صفحات.
- التنقل بين الصفحات، والانتقال المباشر إلى رقم صفحة، واستعادة آخر موضع قراءة تلقائيًا.
- حفظ عدة علامات مرجعية والعودة إليها، مع حفظ التقدم محليًا على الجهاز.
- هدف يومي قابل للتعديل، وعدّاد للصفحات التي تم فتحها اليوم والصفحات التي زارها القارئ.
- اختيار السورة والبحث بأشكال عربية شائعة، والرسم العثماني أو المبسط، وتكبير وتصغير خط القراءة.
- وضع ملء الشاشة، ومظهر ليلي، وألوان متعددة، وتصميم متجاوب، ودعم تثبيت الموقع كتطبيق.
- الاستماع إلى الآيات واختيار القارئ وحفظ اختياره، والانتقال التلقائي بين آيات السورة.
- تكرار الآية مرة أو مرتين أو 3 أو 5 أو 10 مرات أو باستمرار.
- تلوين أحكام التجويد عند توفر بياناتها ومطابقتها حرفيًا مع نص الآية.
- وضع تدريب لإخفاء كلمات الآية ومراجعتها. التعرف الصوتي غير متاح في الواجهة حتى نشر وربط خدمة المحرك.

## مصدر النص القرآني
يتم جلب النص عند الحاجة من Quran.com Content API v4، ثم التحقق من ترتيب الآيات وعددها ومطابقة بيانات الصفحة قبل العرض. لا توجد نسخة نصية محلية بديلة أو نصوص منشأة يدويًا. راجع [توثيق الآيات حسب الصفحة](https://api-docs.quran.com/docs/content_apis_versioned/4.0.0/verses-by-page-number/) و[توثيق الآيات حسب السورة](https://api-docs.quran.com/docs/content_apis_versioned/4.0.0/verses-by-chapter/).

بيانات النص المرجعية من مشروع تنزيل (Tanzil) متاحة أيضًا وفق شروط الاستخدام: https://tanzil.net/docs/text_license

## التخزين دون اتصال
يخزّن Service Worker ملفات الواجهة وصفحات القرآن التي سبق تحميلها. يحتاج فتح صفحات جديدة لأول مرة إلى اتصال بالإنترنت. لا يتم تخزين الصوتيات. تُحفظ العلامات المرجعية وإعدادات المظهر والهدف اليومي محليًا في المتصفح.

## تشغيل محلي
افتح الموقع عبر خادم ملفات ثابت يدعم Service Worker (مثل Live Server)، ثم افتح `index.html`. لا يكفي فتح الملف مباشرة باستخدام `file://` لتجربة التثبيت والعمل دون اتصال.

## محرك التسميع
خدمة التعرف الصوتي المستقلة داخل `asr-api/` جزء من المستودع نفسه. لم يتم نشرها بعد، لذلك زر التسميع الصوتي معطّل بوضوح ولا يدّعي أن الميكروفون أو الذكاء الاصطناعي يعملان. راجع `asr-api/README.md` لتشغيل الخدمة واختبار نقطة الصحة قبل تفعيل الربط.

## التحقق
- `node --check app.js`
- `node --check service-worker.js`
- `python tests/check_site.py`
- `python -m py_compile asr-api/app.py`
